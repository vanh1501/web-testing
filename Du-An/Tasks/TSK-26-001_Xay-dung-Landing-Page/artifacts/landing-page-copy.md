* **Năm 1: Scratch Creator (9-11 tuổi)**

  * **Nội dung học:**
    * Con hiểu game loop: "lặp mãi: nếu nhấn phím -> nhân vật di chuyển, nếu chạm enemy -> game over". Đây là nền tảng của MỌI ngôn ngữ lập trình.
    * Con debug như developer: game lỗi -> tìm block sai -> sửa -> test lại. Rèn luyện tư duy giải quyết vấn đề (problem-solving) thực chiến.
    * Con thuyết trình sản phẩm: Cuối khóa, con tự tin demo và thuyết trình về game tự chế trước lớp và gia đình.
  * **Sản phẩm đầu ra:** Game platformer (nhân vật nhảy qua chướng ngại vật), Quiz app (câu hỏi + điểm + xếp hạng).
* **Năm 2: Game Creator (11-13 tuổi)**

  * **Nội dung học:**
    * Con học GML (GameMaker Language) - ngôn ngữ lập trình text-based viết chữ thật đầu tiên, làm nền tảng vững chắc cho mọi ngôn ngữ sau này.
    * Con tích hợp trí tuệ nhân tạo (AI) vào game: Finite State Machine cho enemy AI, thuật toán tìm đường (pathfinding), hành vi NPC thông minh.
  * **Sản phẩm đầu ra:** Game 2D chuyên nghiệp, Game AI tương tác thông minh, Game xuất bản chạy trực tiếp trên Web.
* **Năm 3: App Producer (12-14 tuổi)**

  * **Nội dung học:**
    * Con lập trình bằng ngôn ngữ Python thực chiến chuẩn doanh nghiệp.
    * Con thiết kế UI/UX với công cụ Qt Designer: kéo thả giao diện đồ họa, kết nối logic để tạo ra App đẹp mắt và sử dụng được trong đời thực.
    * Con tích hợp AI vào App: Lập trình tính năng nhận diện hình ảnh, trợ lý ảo thông minh, kết nối các dịch vụ Google API.
  * **Sản phẩm đầu ra:** App Python AI, App nhận diện hình ảnh, App trợ lý ảo.
* **Năm 4: Web Developer (15-17 tuổi)**

  * **Nội dung học:**
    * Con làm chủ bộ công cụ HTML/CSS/JS + Bootstrap - nền tảng của mọi website, kết hợp với GitHub để quản lý code và API kết nối dữ liệu.
    * Con hiểu bản chất cách Internet vận hành: Tên miền (domain), lưu trữ đám mây (hosting), cơ chế browser render, cloud deploy...
    * Con tự deploy website lên nền tảng cloud: Sản phẩm live trực tiếp trên internet, có người dùng thật truy cập và sở hữu portfolio cá nhân.
  * **Sản phẩm đầu ra:** Website portfolio cá nhân, Website thương mại điện tử, Website tích hợp AI thông minh.
* **Năm 5: Computer Scientist (15-17 tuổi)**

  * **Nội dung học:**
    * Con hiểu sâu sắc về Thuật toán và Cấu trúc dữ liệu nâng cao: Nền tảng vàng cho mọi kỳ thi lập trình quốc tế và phỏng vấn công nghệ lớn.
    * Con xây dựng mô hình Trí tuệ nhân tạo & Học máy (AI/ML): Từ khâu thu thập dữ liệu (data collection), huấn luyện mô hình (model training), đến triển khai ứng dụng AI thực tế.
    * Con có dự án chuyên sâu cá nhân: Portfolio đỉnh cao để sẵn sàng nộp hồ sơ xin học bổng du học, ứng tuyển thực tập (internship) hoặc làm dự án freelance.
  * **Sản phẩm đầu ra:** Ứng dụng AI/ML thực tế, Mô hình Machine Learning, Dự án nghiên cứu chuyên sâu.

Giúp con hiểu cách doanh nghiệp vận hành thực tế từ bên trong (Marketing, Sales, Operations, Finance). Đây là nền tảng vững vàng cho cả mục tiêu khởi nghiệp tự chủ lẫn làm việc tại các tập đoàn đa quốc gia lớn:

* **Level 1: Marketing & Communication:** Học tiếp thị, truyền thông thương hiệu, viết nội dung (content creation) - kỹ năng vàng mọi ngành nghề đều cần.
* **Level 2: Sales & Operation:** Quy trình bán hàng, vận hành hệ thống, chăm sóc khách hàng (CSKH) - thấu hiểu cách doanh nghiệp tạo ra doanh thu.
* **Level 3: Finance & Accounting:** Quản lý tài chính, kế toán, kỹ năng đọc và phân tích báo cáo doanh nghiệp - ngôn ngữ tư duy của mọi CEO.
* **👉 Kết quả:** Con được trải nghiệm thực tế **thử sức 3 ngành nghề** để thấu hiểu năng lực bản thân trước khi chọn ngành học tại Đại học - hạn chế tối đa rủi ro chọn sai ngành nghề.

   * **Trả lời:** Học lập trình giúp con thay đổi hoàn toàn lăng kính khi nhìn vào game.
