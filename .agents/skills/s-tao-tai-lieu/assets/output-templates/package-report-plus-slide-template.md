# Mẫu: Package Báo cáo + Slide

## 1. Mục đích

Dùng khi cần một bộ tài liệu gồm báo cáo chi tiết và slide tóm tắt cho cuộc họp/phê duyệt.

## 2. Output cần tạo

| File | Mục đích | Người đọc |
|---|---|---|
| `report-docx-ready.md` | Báo cáo chi tiết | Người duyệt cần đọc kỹ |
| `executive-slides.marp.md` | Slide tóm tắt 5-8 trang | Cuộc họp/pitch |
| `handoff-note.md` | Cách dùng bộ tài liệu | Người vận hành |

## 3. Cấu trúc slide gợi ý

1. Title + conclusion.
2. Problem/context.
3. Key insight 1.
4. Key insight 2.
5. Recommendation.
6. Decision / next steps.

## 4. Checklist

- [ ] Báo cáo và slide không mâu thuẫn.
- [ ] Slide không copy nguyên văn báo cáo.
- [ ] Báo cáo có appendix nguồn.
- [ ] Có note rõ file nào gửi cho ai.
