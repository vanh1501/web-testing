# Context & Memory Ops

Bác Sĩ Phẫu Thuật FinOps & TokenOps chuyên tối ưu Context và kiến trúc Bộ nhớ (Memory Contract). Dò quét, bóc tách RAG Pointers vào các Tệp tin Béo phì (> 15KB). Đồng thời audit và tối ưu memory-contract.yml đảm bảo chuẩn RBAC V2.0 và chống Bloat.

## When to use this skill

- Agent có dấu hiệu loạn trí nhớ (context drift, hallucination tăng).
- Nhận Cảnh báo Vượt 12K Tokens hoặc file > 15KB.
- `/optimize-workspace` yêu cầu sửa chữa liên quan đến context.
- User nói "Audit Memory", "Khóa bộ nhớ", "Fix Memory Contract".
- Cần tạo mới hoặc sửa `memory-contract.yml`.
- **KHÔNG dùng khi:** Xóa bỏ hoàn toàn Luật/KB. Cấm cắt xén Tri thức tĩnh (Phải tiêm RAG thay thế). Không quản lý CSDL SQLite (Dùng `data-warehouse-ops`).

## How to use it

1. Xác định vấn đề: Phình to Context (Route 1) hay lỗi cấu hình Memory Contract (Route 2).
2. Kiểm tra dung lượng và cấu trúc file bị ảnh hưởng.
3. Kích hoạt Route tương ứng để bóc tách hoặc tạo cấu hình.
4. Trả về báo cáo nén hoặc Delta Report.

## When to clarify

- Hỏi ý kiến User trước khi nén hoặc cắt bỏ bất kỳ đoạn văn bản nào có chứa Quyết định chiến lược.
- Báo cáo và xin chỉ đạo khi tổng số Token vượt quá 20K ngay cả sau khi đã nén.

## Decision quan-ly-quy-tac
- If agent has context drift or file > 12K Tokens → **Route 1 (CONTEXT ENGINEERING)**
- If creating/auditing memory contract → **Route 2 (MEMORY BUS ENGINEERING)**

## Process

### Route 1: Context Engineering

> [!WARNING] Bạn phải trích xuất Socratic OTC Check trước khi thao tác Tool

1. Load `references/methodology.md` trước khi thao tác (nếu có).
2. Quét kích thước file. Nếu > 12K Tokens, tiến hành phẫu thuật để đạt mục tiêu LLM Context Window Optimization.
3. Đối với Cấu hình/Luật (Tĩnh): Áp dụng **RAG Pointer Auto-Wire**. Thay vì bắt Agent tự cắt dán nhồi nhét Context Window gây ngập lụt, Skill sẽ tự động dò các đoạn Text Cấu hình (như bảng JSON tĩnh, danh sách tham số), bóc chúng ra lưu thành file riêng ở `KB/`, và nhét lại vào não Agent một chiếc RAG Pointer (`Sử dụng công cụ view_file để đọc file: [path]`).
4. Đối với Lịch sử (Động): Áp dụng **Hierarchical Memory Chunking**. Quản lý cấu trúc bộ nhớ phân cấp: Lịch sử ngắn hạn (Short-term) giữ nguyên, lịch sử dài hạn (Long-term) tự động tóm tắt thành Checkpoint Bullet Point. BẮT BUỘC giữ lại nguyên vẹn các Quyết định chiến lược (Decision Records), chỉ loại bỏ các lời chào/giải thích thừa.
5. Xác nhận Budget Tokens đã xuống vùng an toàn xanh.

### Route 2: Memory Bus Engineering

> [!WARNING] Bạn phải trích xuất Socratic OTC Check trước khi thao tác Tool

1. **CQS Size Gate (Pre-Check):** Any memory contract < 0.5KB → Auto-FAIL (skeleton).
2. Load `references/memory-rbac-rubric.md` + `references/contract-compaction-rules.md`.
2. CREATE: Dùng template `assets/v2-contract-template.yml` → customize cho workspace mới.
3. AUDIT: Kiểm tra RBAC routing, Dual-Write config, Compaction rules trong `memory-contract.yml`.
4. FIX: Xuất Delta Report với YAML đã vá.
- *Lưu ý:* Agent Chóp bu (Orchestrator/Coordinator) luôn phải có quyền `write` ở mảng Dữ liệu Điều phối (`state.json`, `ledger.md`).

## Output format
- Báo cáo kết quả nén (Kích thước trước/sau).
- Hoặc Delta Report YAML nếu sửa memory-contract.

## Quality checklist

- [ ] Kích thước file bị bóc tách đã giảm xuống dưới 15KB chưa?
- [ ] Các Quyết định chiến lược có được bảo toàn nguyên vẹn sau khi nén (Route 1) không?
- [ ] Memory Contract tạo mới/sửa đổi có vượt qua kích thước tối thiểu (0.5KB) không?
- [ ] Agent có được cấu hình quyền `write` phù hợp cho Orchestrator không?

## Guardrails

- `Truncate_Core_Rules` → [DENY]. Tự ý cắt gọt (Truncate) làm rỗng Não của Agent là cấm tuyệt đối.
- `Memory_>_20K_Tokens` → [CIRCUIT BREAKER]. Cháy Cầu Dao! Ngừng suy luận, trả về cho Human.
- `Skip_CQS_Gate` → [DENY]. Memory contract < 0.5KB = skeleton.

## Rules

- `Domain_Index_Read_Only` → [REQUIRE]. File `domain.index` strictly Read-Only for ALL agents.
- `Splice_Pattern` → [REQUIRE]. Phải bóc luật tĩnh sang file nhánh và ép buộc RAG View File.
- `Semantic_Compression` → [REQUIRE]. Lịch sử phải nén thành Checkpoint Bullet, không cắt ngang.
