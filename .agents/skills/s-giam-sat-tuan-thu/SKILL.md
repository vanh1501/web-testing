# Governance Verifier

Kiểm định chuẩn từ ngoài vào trong: Rule Architecture trước, Memory Contract sau, Circuit Breakers cuối cùng. Governance Verifier là người gác cổng, đảm bảo mọi cấu trúc phân quyền và ràng buộc bộ nhớ của MAS Workspace được tuân thủ nghiêm ngặt.

## When to use this skill

- `/audit-workspace` Phase 4 (Governance gate) hoặc Phase 6.5 (Circuit Breakers).
- User nói "audit giam-sat-tuan-thu", "check HPRF", "verify memory contract", "circuit breaker check".
- `/optimize-workspace` delegates giam-sat-tuan-thu-layer findings.
- **KHÔNG dùng khi:** Sửa rule content trực tiếp (dùng `quan-ly-quy-tac` skill). Thiết kế architecture (dùng `architecture` skill).

## How to use it

1. Chạy Gate 1-5 tuần tự (HPRF → Memory Contract → L0/L1 Ratio → Handoff V2.0 → Circuit Breakers).
2. Emit findings với severity (SYSTEMIC-HALT / LOCAL-FIX / WARNING).
3. KHÔNG tự sửa — chỉ emit findings cho downstream (optimizer).

## When to clarify

- Nếu `memory-contract.yml` không ở `.agents/memory_bus/`: hỏi "Workspace này đã migrate sang V8 chưa?"
- Nếu L0 file count > 4: hỏi "File L0 extra có được approve không?" trước khi flag

## Decision quan-ly-quy-tac

- If triggering Phase 4 Audit → **Route 1 (GOVERNANCE AUDIT)**
- If triggering Phase 6.5 Audit → **Route 2 (CIRCUIT BREAKER AUDIT)**

## Process

### Route 1: Governance Audit (Phase 4)

> [!WARNING] Bạn phải trích xuất Socratic OTC Check trước khi thao tác Tool

1. **Gate 0: CQS Size Gate (Pre-Check)**
   - Any agent, workflow, or skill file < 0.5KB → Auto-FAIL (skeleton).
2. **Gate 1: HPRF Tier Verification**
   - Đọc từng file trong `.agents/quan-ly-quy-tac/`. Kiểm tra sự hiện diện của `Override Priority:` block.
   - Load `references/hprf-checklist.md` for validation.
2. **Gate 2: Memory Contract Compliance**
   - Load `references/memory-contract-schema.md`.
   - Run checklist against `memory-contract.yml` at `.agents/memory_bus/`.
3. **Gate 3: L0/L1 Rule Architecture (30/70 Ratio)**
   - Count L0 files (hard-coded quan-ly-quy-tac): MUST = 4.
   - Count L1 files (context quan-ly-quy-tac): MUST > 0 AND có fallback.
   - **Epistemic Blast Radius Calculator (ITIL Impact Analysis):** Tính toán vùng sát thương nếu Rule L0 hiện tại bị thay đổi, dựa trên tiêu chuẩn quản lý thay đổi ITIL. Nếu một Rule L0 đang được Import (trỏ tới) bởi hơn 5 Workflow/Agent, hãy đóng băng (khóa cảnh báo Đỏ - SYSTEMIC-HALT) cảnh báo cấm sửa đổi tùy tiện khi audit, yêu cầu quy trình duyệt thay đổi (Change Advisory Board - CAB) của User.
4. **Gate 4: Handoff V2.0 State Machine**
   - Check `handoff-protocol.md` hoặc embedded handoff quan-ly-quy-tac.

### Route 2: Circuit Breaker Audit (Phase 6.5)

> [!WARNING] Bạn phải trích xuất Socratic OTC Check trước khi thao tác Tool

1. **Gate 5: Circuit Breaker Patterns**
   - Load `references/circuit-breaker-patterns.md`.
   - Verify OPEN, HALF-OPEN, CLOSED states, and HITL escalation.


- [ ] Were physical reference files loaded before validation?

## Guardrails

- `Attempt_Code_Fix` → [HALT]. Must delegate to `workspace-optimizer`.
- `Missing_Memory_Contract_At_Memory_Bus` -> [SYSTEMIC-HALT].
- `Skip_CQS_Gate` → [DENY]. File < 0.5KB = skeleton.

## Rules

- `Finding_Format_Violation` → [DENY]. MUST include: Gate number + Finding ID + File reference + Line (if applicable) + Severity.
- `Emit_PASS_Without_Evidence` → [DENY]. Line reference or field name is mandatory for PASS.
- `Auto_Edit_Files` → [DENY]. Emit findings for downstream optimizer only.
- `Run_Gate_Without_Reference` → [DENY]. ALWAYS load respective reference file first.
