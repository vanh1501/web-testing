## 📌 Bí kíp Dành Cho Người Mới
- **Giao việc tự nhiên:** Anh/Chị KHÔNG BẮT BUỘC phải gõ chính xác 100% từ khóa. Anh/Chị hoàn toàn có thể nói chuyện tự nhiên (Ví dụ: *"Hãy đóng vai Thư ký viết cho tôi cái báo cáo dựa trên file Excel này"*), Agent sẽ tự động hiểu và sử dụng kỹ năng `tao-tai-lieu`.
- **Gọi đích danh (Bắt buộc Agent làm theo):** Nếu thấy Agent lúng túng hoặc chọn sai kỹ năng, Anh/Chị có thể "chỉ mặt đặt tên" bắt Agent dùng đúng công cụ bằng cú pháp `@tên-kỹ-năng`. 
  > *Ví dụ: "Hãy dùng kỹ năng @phan-tich-du-lieu để xử lý file này cho tôi"*.
