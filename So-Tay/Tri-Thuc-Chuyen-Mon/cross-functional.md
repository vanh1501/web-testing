# Cross-Functional Thinking — Shared Knowledge

## TL;DR
4 công cụ tư duy dùng xuyên suốt mọi domain. Pyramid (structure output), MECE (phân loại), Issue Tree (chẩn đoán), Decision Matrix (so sánh).

## 1. Pyramid Principle
**Khi nào**: Mọi output >200 từ
**Cách dùng**: Recommendation TRƯỚC → 2-3 Arguments hỗ trợ → Evidence per argument
**CẤM**: Viết kiểu diễn dịch (kể chuyện rồi mới kết luận)
**Ví dụ đúng**: "Đề xuất chuyển sang Notion vì: (1) Tiết kiệm 30% thời gian quản lý, (2) Team đã quen interface, (3) Chi phí thấp hơn Monday 40%"
**Ví dụ sai**: "Hiện tại team dùng Excel, có nhiều vấn đề... sau khi tìm hiểu... kết luận nên dùng Notion"

## 2. MECE Decomposition
**Khi nào**: Phân loại vấn đề, nhóm tasks, phân tích nguyên nhân
**Cách dùng**: Mỗi category KHÔNG trùng nhau (mutually exclusive) + tổng tất cả categories = toàn bộ (collectively exhaustive)
**Test**: "Có item nào thuộc 2 categories không?" (phải = Không) + "Có item nào không thuộc category nào?" (phải = Không)

## 3. Issue Tree
**Khi nào**: Phân tích nguyên nhân gốc, chẩn đoán vấn đề
**Cách dùng**:
```
Vấn đề gốc
├── Nhóm A → Nguyên nhân A1 → Evidence? → Action?
├── Nhóm B → Nguyên nhân B1 → Evidence? → Action?
└── Nhóm C → Nguyên nhân C1 → Evidence? → Action?
```
**Rule**: Mỗi nhánh phải có evidence hoặc ghi rõ "cần data để verify"

## 4. Decision Matrix
**Khi nào**: So sánh ≥2 options, cần recommend
**Cách dùng**:
1. Liệt kê criteria (4-7)
2. Assign weight (tổng = 100%)
3. Score mỗi option per criteria (1-5)
4. Weighted total → Recommend option cao nhất
**Rule**: PHẢI note trade-offs. Option tốt nhất vẫn có điểm yếu — nói rõ

## 5. "So What?" Test
Áp dụng cho MỌI output: sau mỗi finding/analysis, tự hỏi:
- "So what?" → Tại sao điều này quan trọng?
- "Now what?" → Nên làm gì tiếp theo?
Nếu không trả lời được → finding chưa đủ actionable
