Tư duy Logic & Thuật toán Kéo thả

Trọng tâm đào tạo
  • Con hiểu game loop: "lặp mãi: nếu nhấn phím -> nhân vật di chuyển, nếu chạm enemy -> game over". Đây là nền tảng của MỌI ngôn ngữ lập trình.
  • Con debug như developer: game lỗi -> tìm block sai -> sửa -> test lại. Tư duy problem-solving (giải quyết vđề) thực chiến.
  • Con present sản phẩm: cuối khóa, con demo game trước lớp và gia đình.
