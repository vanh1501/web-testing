# Tiêu chí kiểm thử

## Pass khi
- Input đủ angle, CTA, audience, section giữ nguyên.
- Copy bám angle.
- Problem/Why/USP show, don’t tell.
- Why không educate chung chung.
- USP map với problem.
- CTA đúng input.
- Claim nhạy cảm được flag.
- HTML mở được, responsive cơ bản.
- Hero có form + CTA.
- GitHub handoff không tự publish.

## Fail khi
- CTA sai input.
- Claim bị bịa.
- Section giữ nguyên bị sửa.
- HTML thiếu form/viewport.
- Agent claim đã publish khi mới handoff.
